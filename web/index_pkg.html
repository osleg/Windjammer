M-VAVE FM-1 controller firmware @VERSION@

Install over USB

  1. Back up any projects, samples, or settings you want to keep using your current firmware’s tools.
  2. Plug one powered FM-1 directly into this computer with a USB data cable, and close other apps using its MIDI port.
  3. Open this page in desktop Chrome or Edge and allow MIDI access when prompted.

Keep the device powered and connected until it restarts. If it comes back in update mode, reconnect and start again.
